# Slice 08 — Syllabus

Read `CLAUDE.md` first.

## Goal

Each course shows its topics in order, what I have covered, and what I have not
touched. This is the backbone slice 12 hangs its payoff on.

## Build

1. **`/courses/[id]`** — the course page: ordered syllabus units, each showing
   status, minutes studied (from `modules/study`), notes linked to it, and tasks
   linked to it.

2. **Status setting** — `not_started` / `shaky` / `comfortable` / `mastered`, set by
   me in one tap. No automatic inference yet.

3. **Progress** per course, honest about what it measures — units marked comfortable
   or better, not a fake percentage.

4. **Linking** — a note or task can be attached to a unit from either side.

5. **Unit editing** — add, rename, reorder units inline. I will be typing my syllabus
   in from a PDF, so make this fast and boring: type, enter, type, enter.

## Constraints

- No AI in this slice. Status is manual.
- No charts.

## Definition of done

I will: type in the full syllabus for one real course, mark a few units, and see at a
glance which units I have never opened.

## Then

Update `docs/SLICES.md`. Print the summary. Stop.
